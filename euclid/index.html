Autoformalization · Lean 4

Can an AI rewrite Euclid into a language a computer can check?

And if it can — what actually decides whether it works: the wording of the math, or how you ask?

A study by Reza Ramji · GPT-4o · 2,653 runs

Euclid, Book I · human prose

On a given finite straight line AB, to construct an equilateral triangle.

Lean 4 · machine-checkable

theorem prop_I_1 (A B : Point) : ∃ C, equilateral A B C := …

prose → formal · if it compiles & checks, it is correct — no trust required

Scroll

The problem

A proof in a textbook is written for people. Lean 4 is a language a computer can verify, line by line: if a Lean proof compiles and type-checks, it is correct — no appeal to authority required.

Translating ordinary mathematical prose into Lean by hand is slow expert work. The hope of autoformalization is that a language model can do the translation for us. This study asks a narrow, testable version of that question, using the oldest textbook we have: Euclid's Elements.

The experiment

Three translations, one geometry

The same 48 propositions, in three voices.

01 · The source material

The same proof, three voices

Euclid's Book I — the same 48 propositions — survives in sharply different English. Heath (1908) is archaic and Victorian; Fitzpatrick (2007) is modern academic, naming its variables explicitly; Modern is a plain paraphrase.

They say the same things. So: does the register change how well GPT-4o turns a proposition into Lean?

02 · The trap

It looked like Fitzpatrick won

An early run used one prompt template whose five worked examples were all in Fitzpatrick's style. Fitzpatrick text seemed to formalize best — beating Heath by 8.4 points (p=0.008).

But that confounds two things. The Fitzpatrick translation also matched the examples in the prompt. Was it the register — or just input that looked like the demo?

03 · The fix

Cross every register with every prompt

To pull the two apart, we crossed them: three translation registers × three prompt styles, fully counterbalanced. Every translation now faces every prompt.

A 3×3 design over 143 propositions (Book I plus 100 UniGeo theorems) — 2,653 runs in all.

04 · Read it down

Fix the prompt — translation barely moves

Hold a prompt style constant (read down a column) and the three translations land within a few points of each other. The register you feed in hardly matters.

Statistically: no significant effect (p=0.603).

05 · Read it across

Change the prompt — everything collapses

Now read across a row. Swap the prompt style and the compile rate falls off a cliff — from 72.6% with the best style to 48.4% with the worst.

A 24-point swing (p<0.001). The lever is the prompt, not the prose.

06 · The mirage, dispelled

The original gap only existed in one column

"Fitzpatrick wins" shows up only under Fitzpatrick-style prompts. Under Heath prompts it reverses (65.5% > 60.0%); under Modern prompts it reverses again.

On the 100 independent UniGeo theorems, Heath even beat Fitzpatrick by 6.2 points — the opposite of the first claim.

07 · The model that cheated

One model scored highest on no math at all

We first tried a small local model, Qwen2.5-Coder-7B, on a Jetson Orin Nano. It had memorized the benchmark: its best compile rate came from feeding it nothing but "Proposition N."

Empty input beats full text. A clean model (GPT-4o) does the opposite — 10% from empty, 67.9% from the real proof. So we dropped Qwen and ran everything on GPT-4o.

How you prompt matters.
Which translation you feed in does not.

The statistics, briefly

A mixed-effects regression with proposition as a random intercept (N=2,653) confirms the picture: translation coefficients are tiny and not significant; prompt coefficients are large and significant. Adding prompt style improves model fit by 99.5 AIC points; adding a prompt×translation interaction does not help.

What this means in practice

If you want to use autoformalization on your own mathematics, the lever isn't cleaning up your prose — it's styling your few-shot examples to match how you write, especially whether they introduce variables explicitly.

Two methodological notes fall out. First, a single prompt template can manufacture a fake "wording" effect, so counterbalanced prompt designs should be the default. Second, the empty-input probe — does the model compile from just "Proposition N"? — is a cheap memorization check worth running before anyone reports autoformalization numbers.

Honest limits

  • One model. The counterbalanced results are GPT-4o only; the Qwen runs are void due to contamination. Prompt sensitivity may differ elsewhere.
  • Compiling isn't being correct. Compile rates overstate real performance. On the semantically scored subset: 14% strict equivalence, 30% correct-direction. The 24-point prompt effect is measured on compilation, not correctness.
  • Uneven cells. Fitzpatrick-prompt cells carry 430 runs each; Heath and Modern prompt cells have 133–235. The model handles the imbalance, but precision varies.
  • UniGeo, one prompt. The 100-theorem replication used only Fitzpatrick-style prompts, so it confirms the translation non-effect but not the prompt effect.
