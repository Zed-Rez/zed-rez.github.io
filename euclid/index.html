Few-Shot Prompt Style Dominates Translation Choice in Autoformalization

Key Findings

Translation has no significant effect on autoformalization success (p=0.603) once prompt style is controlled. Prompt style drives a 24pp range in compilation rate (72.6% vs. 48.4%, p<0.001). An initial finding that Fitzpatrick's translation outperforms Heath's (8.4pp, p=0.008) was entirely a prompt-translation confound.

Qwen2.5-Coder-7B has memorized the LeanEuclid benchmark. The model achieves its highest compile rate — 62.8% — from empty input (just "Proposition N"), with 100% of outputs using LeanEuclid-specific predicates. GPT-4o is clean: 10% from empty input vs. 67.9% from full text.

Setup

Euclid's Elements Book I exists in three radically different English registers, all expressing the same 48 propositions: Heath (1908, archaic Victorian), Fitzpatrick (2007, modern academic with explicit variables), and a minimal contemporary paraphrase. Using GPT-4o and the LeanEuclid benchmark (Murphy et al., 2024), we asked: does the English register affect formalization into Lean 4?

The Confound

Phase 2 used a single prompt template whose five few-shot examples were written in Fitzpatrick's style. This confounded prompt with translation: the Fitzpatrick translation was "in-distribution" for the prompt. Phase 3 disentangled the two by creating three prompt templates (Fitzpatrick-style, Heath-style, Modern-style) for a fully crossed 3×3 design across 143 propositions (Book I + 100 UniGeo theorems, 2,653 total observations).

However, semantic equivalence drops to 0% under the empty condition (vs. 16–27% with garbled text), confirming the model does read input for semantic refinement but does not need it for structural generation.

Caveats

  • Single model. All counterbalanced results are for GPT-4o. Prompt sensitivity may differ for other models; the Qwen results are invalidated by contamination.
  • Compilation ≠ correctness. Compile rates overstate real performance. E3 semantic equivalence on the subset scored: 14% strict equivalence, 30% correct-direction (equiv + stronger). The 24pp prompt effect is measured on compilation, not semantic correctness.
  • Unbalanced cells. Phase 2 data (430 observations per cell) was retained for Fitzpatrick-prompt conditions; Heath and Modern prompt cells have 133–235 observations. The mixed-effects model handles unbalanced designs, but precision differs across cells.
  • UniGeo tested with a single prompt. The 100-theorem replication set uses only Fitzpatrick-style prompts, so it cannot independently confirm the prompt main effect — only the translation non-effect.
  • Contamination is a general hazard. Models trained on GitHub will encounter formal verification repositories. The empty-input probe (compare compile rate from "Proposition N" versus full text) is a lightweight audit that should be standard practice before reporting autoformalization results.

Takeaway

Few-shot prompt style — particularly whether examples include explicit variable introductions — is the primary lever for autoformalization on Euclidean geometry. Studies using a single prompt template cannot distinguish translation effects from prompt-style matching. The practical implication: mathematicians hoping to use autoformalization should invest in styling their few-shot examples to match their writing register, not in cleaning up their source text.
