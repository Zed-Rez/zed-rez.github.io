Projects

Independent research with Princeton University Library on recognizing ancient coins from images — custom OCR for worn, hand-struck lettering, working with very little training data. Reach out if you work on OCR, coins and machine learning, or learning from small datasets.

Youklid

Euclid's Elements, Book I, annotated so you can see exactly which earlier results each proof leans on — and a place to test those steps with AI. open · source

Euclid → Lean 4

Can a small AI model rewrite Euclid's proofs in Lean, a language a computer can check? A controlled study found the example style in the prompt mattered more than which English translation was used — and that small models quietly memorize, so you have to test for it. read

CASE-Bench

A benchmark that checks whether an AI can suggest business ideas that would actually work, not just the safe and obvious ones. Ideas are scored by a panel of model judges, and the results come with real statistics. read · source

llm-eval

A small A/B harness for comparing language models head-to-head, built to re-check a published claim about how models recall names — it still holds up on current models. source

Logion + weighted Levenshtein

An improvement to Princeton's Logion, which restores missing words in damaged ancient Greek. Instead of treating every letter swap as equally likely, it weights them by how easily letters are confused — measurably better on Photius. read · source

EdgarVis

A 3D map of US public companies built from decades of SEC 10-K filings — ~12k companies over 17 years. Try the die next to the search bar to land on strange ones. open · source

EdgarInsights

The same SEC data as a flat dashboard — by metric and year, with notes on what stands out. open

Chain audio

Live USDC transfers across nine blockchains, turned into sound as they happen. open

MCP ingest

A bulk-ingest tool for Claude Code that runs agents in parallel with prompt caching — about 89% cheaper than running them separately. source
